# Early Risk Detection System

## Overview

A Machine Learning based system that predicts software project risk levels.

The system classifies projects into:

- Low Risk
- Medium Risk
- High Risk


## Technologies Used

- Python
- Flask
- XGBoost
- Scikit-learn
- Pandas
- NumPy
- Firebase/MySQL


## Machine Learning Model

Best Performing Model:

XGBoost Classifier


## Dataset Features

The model uses:

- Team Information
- Project Characteristics
- Timeline Metrics
- Task Metrics
- Bug Quality Metrics
- Development Activity


## System Workflow

The overall workflow of the system is:


Project Data Upload
